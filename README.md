# 現場収支クラウド（下請けリフォーム・自営業専用）

> **「receipt-app」のレシート読取・支出管理をベースに、下請けリフォーム業者の現場業務と弥生会計API連携に特化して構築した収支管理Webアプリケーション**

---

## 🏗️ 開発の背景とリフォーム下請け業者の課題解決

個人事業主や一人親方・少人数でリフォーム下請け工事（大工・内装・水回り設備・塗装等）を請け負う事業者様は、一般的な家計簿アプリや汎用会計ソフトでは以下の課題を抱えがちでした：

1. **「現場（案件）ごとの粗利」が見えない**:
   - ホームセンター（コーナンPRO、カインズ等）で買った資材や現場コインパーキング代が、どの元請けのどの現場で発生した経費なのか後から分からなくなる。
2. **応援職人の人工（にんく）計算と源泉徴収の複雑さ**:
   - 応援の大工や電気屋さんに支払う日当・人工と、源泉徴収税額（10.21%控除）の管理が煩雑。
3. **弥生会計への二重入力の手間**:
   - レシートをスマホで管理しても、確定申告や帳簿のために弥生会計へ手動で再入力する必要があった。

本アプリは、これらを**ワンストップで解決**するために設計されています。

---

## ✨ 主要機能一覧

### 1. レシート・領収書OCRかんたん読取（receipt-appコア機能の進化版）
- スマホカメラでの現場撮影、レシート画像のドラッグ＆ドロップ取込
- 店舗名（コーナンPRO、カインズ、モノタロウ、タイムズ等）、取引日、金額、内消費税（10%/8%軽減）を自動認識
- **現場案件とのスマート自動紐付け**: 施工中の現場を自動推論またはワンクリックで割当
- 弥生会計勘定科目（材料費/仕入高、旅費交通費、消耗品費等）の自動判定

### 2. 現場（工事案件）別リアルタイム粗利管理
- 元請会社名（工務店・リフォーム会社等）、請負金額（売上）、工期、ステータス（施工中・完工・請求済・入金済）
- 現場投入原価（材料費＋外注応援人工＋現場直接経費）の自動集計
- **現場ごとの粗利益・粗利率（%）をリアルタイム可視化**
- 請求ステータス・入金期日アラート（売掛金回収漏れ防止）

### 3. 外注・応援職人の人工（にんく）管理
- 応援職人の稼働日、工種（大工、内装、電気、設備等）、人工数（0.5, 1.0, 1.5, 2.0等）、日当単価の記録
- **源泉所得税額（10.21%）の自動計算**
- 職人への差引手取支払額と現場原価への自動反映

### 4. 弥生会計 連携ハブ（API連携 ＆ CSVエクスポート）
- **弥生会計オンライン スマート取引取込API**:
  - OAuth 2.0 認証によるセキュアな直接連携
  - 未送信の仕訳を一括で「スマート取引取込」へワンクリック送信
  - 弥生側で採番される仕訳ID（`YY-YYYYMM-XXXX`）を自動記録し、二重計上を完全に防止
- **弥生会計 仕訳日記帳 CSVインポート（デスクトップ版・オンライン版両対応）**:
  - 弥生会計の公式25列インポートフォーマットに完全準拠
  - 個人事業主・一人親方の定番である貸方科目「事業主借」や「未払金（カード）」「普通預金」に完全対応
  - ダウンロードして弥生会計の「ファイル > インポート」から即座に取込可能

## 🔒 弥生会計API仕様概要
- エンドポイント: `https://api.yayoi-kk.co.jp/smart-connect/v1/journals` (OAuth2 Bearer Token)
- 取引取込ペイロード:
  - 借方科目: `材料費（仕入高）`, `旅費交通費`, `外注費`, `消耗品費` など
  - 借方補助科目: 店名（コーナンPRO等）または現場名
  - 貸方科目: `事業主借`（個人立替） / `未払金` / `現金` / `普通預金`
  - 税区分: 課税仕入 10% / 課税仕入 8%(軽)
  - 摘要: `【現場名】店舗名 品目メモ`
